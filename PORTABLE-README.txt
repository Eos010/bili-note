bili-note V3 便携版 · 使用说明
================================

1. 解压到可写目录
   建议：D:\bili-note   或   D:\Tools\bili-note
   ❌ 不要放在 C:\Program Files 下（程序要把 config.json / output / models 写在旁边，那里没有写权限）。

2. 双击 bili-note.exe
   第一次会弹出「欢迎使用 bili-note V3」向导：
   - 先检查这台机器的显卡 / CUDA / ffmpeg / 磁盘；
   - 模型默认不下载。绿色「推荐下载」的模型可以点「下载并开始」；
   - 只想先存视频，点「先不下载，仅下载视频」即可跳过。
   浏览器会自动打开 http://127.0.0.1:8001（被占用时自动换 8002…）。

3. 模型下载在哪里
   默认：<解压目录>\models\
   可以在「设置 → 转写模型」里改成任意可写磁盘（例如 D:\bili-note-models），
   点「保存这些设置」后生效。下载、加载、删除都只认这个目录，不会再跑到 C 盘缓存。

4. 默认模型
   small（约 464MB），CPU 也能跑，适合先体验。
   有 NVIDIA 显卡且显存 ≥8GB 时，向导会绿色推荐 large-v3（约 2.95GB）。
   红色「配置不足，不推荐」的模型仍可强行下载，但会很慢或跑不动。

   注意：文件名带 `-cpu-` 的轻量包不含 cublas，只能用 CPU；
   要用 GPU 请下载不带 `-cpu-` 的完整包（约 835MB）。

5. 关闭
   直接关掉黑色控制台窗口；或者双击 stop.bat（源码版）。

6. 常见问题
   - 下载源：默认国内镜像 hf-mirror.com；也可以在设置里切官方 / 填代理。
   - 模型下载断了：已下载的部分会保留，再点「下载」会续传。
   - 端口被占用：程序会自动换端口并打开正确的地址。
   - 杀毒/SmartScreen：未签名 exe 可能提示「Windows 已保护你的电脑」，
     点「更多信息 → 仍要运行」。这是未做代码签名的正常提示。
   - 只下载视频不需要模型；粘 .txt 文稿做总结也不需要模型。
   - 卸载：删除整个文件夹即可。models 和 output 都在里面，想保留就先拷走。

7. AI 总结（可选）
   右上角 ⚙ → 填 DeepSeek 的 API Key 后才能用总结；只转写不填也能用。
